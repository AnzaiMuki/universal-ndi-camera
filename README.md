# Universal NDI Camera

Transformez vos telephones Android en cameras NDI. L'application filme et diffuse ; **Le Pont** (Windows) republie chaque flux en source NDI pour OBS, vMix ou TriCaster.

Les versions (application + Le Pont) sont publiees dans l'onglet **Releases**.

_NDI(R) est une marque de Vizrt NDI AB. Projet non affilie a Vizrt._
